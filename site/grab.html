Grab deals bookmark

For MEC, REI, SVP Sports and Hoka (test), which don't allow automated collection. You browse their sale page as usual; this bookmark saves what's listed so your site and Friday email include it.

Grab deals

On your iPhone (set up once)

  1. Tap
  2. In Safari, tap the Share button on this page → Add Bookmark → name it Grab deals → Save.
  3. Open your bookmarks (the book icon) → Edit → tap Grab deals → tap the address line, delete it, paste → Done.

On your iPhone (every few days)

  1. Open MEC running deals or REI running deals.
  2. Tap the address bar, type Grab, and tap the Grab deals bookmark in the list. Keep the tab open while it reads (about 1–2 minutes for REI).
  3. Tap Send to The Gear Fox. A new tab opens and says "Saved". The first time, it asks for your private key (Supabase → Table Editor → ana_settings → dashboard_key, the same as the data page).
  4. That's it: the site updates by itself in about 20 minutes. No file, no GitHub.

On a computer (set up once)

  1. Show your bookmarks bar (Safari: View → Show Favourites Bar; Chrome: Cmd+Shift+B).
  2. Drag the yellow Grab deals button onto the bar.

On a computer (every few days)

Same as the phone: click the bookmark, then Send to The Gear Fox. The old way still works too: "or download the file", then upload it to saved-pages on GitHub.

  1. Open MEC running deals, click Grab deals, wait for "products saved". A file mec-DATE.json downloads.
  2. Open REI running deals (sort by Percent Off if you like), click Grab deals. A file rei-DATE.json downloads.
  3. Open SVP Sports, go to the running section and pick the sale / "Solde" filter (any product list works), click Grab deals. A file svp-DATE.json downloads.
  4. Hoka (test): open hoka.com/en/ca, go to the sale running shoes, scroll to the bottom so every shoe loads, click Grab deals. It only saves what's on your screen. File saved.
  5. On GitHub, open the saved-pages folder → Add file → Upload files → drag in both files → Commit.

It reads up to 20 MEC pages and 15 REI pages, about 2 seconds apart, just like clicking "next". Files older than 10 days are ignored automatically, so you never need to delete old ones.
