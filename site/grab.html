Grab deals bookmark

For MEC, REI, Backcountry, SVP Sports and Hoka (test), which don't allow automated collection. You open a product list as usual (sale or all running gear); this bookmark saves what's listed so your site and Friday email include it.

Grab deals

On your iPhone or iPad (set up once)

  1. Tap
  2. In Safari, tap the Share button on this page → Add Bookmark → name it Grab deals → Save.
  3. Open your bookmarks (the book icon; on an iPad, the sidebar button at top left) → Edit → tap Grab deals → tap the address line, delete it, paste → Done.

On your iPhone or iPad (every few days)

Any product list works: the sale page (fast) or all running gear (full price too, so people can watch for a drop). Do both now and then: the site combines everything you sent in the last 10 days.

  1. Open a list:
    MEC: running deals · for all running gear, open MEC's Running menu and pick a list (Running shoes, Running clothing, Running accessories...)
    REI: running deals · all running
    Backcountry: running shoes · running clothing (it opens every product for its sizes, sale items first, 4 at a time. Tap "Send what's read so far" whenever you want: next time it continues where it stopped, and the site keeps every send for 10 days)
  2. Tap the address bar, type Grab, and tap the Grab deals bookmark. Keep the tab open while it reads: a minute or two for a sale page, up to 5 minutes for all of REI's running gear.
  3. Tap Send to The Gear Fox. A new tab opens and says "Saved". The first time, it asks for your private key (Supabase → Table Editor → ana_settings → dashboard_key, the same as the data page).
  4. That's it: the site updates by itself in about 20 minutes. No file, no GitHub.

On a computer (set up once)

  1. Show your bookmarks bar (Safari: View → Show Favourites Bar; Chrome: Cmd+Shift+B).
  2. Drag the yellow Grab deals button onto the bar.

On a computer (every few days)

Same as the iPhone/iPad: click the bookmark, then Send to The Gear Fox. The old way still works too: "or download the file", then upload it to saved-pages on GitHub.

  1. Open MEC running deals, click Grab deals, wait for "products saved". A file mec-DATE.json downloads.
  2. Open REI running deals (sort by Percent Off if you like), click Grab deals. A file rei-DATE.json downloads.
  3. Open SVP Sports, go to the running section and pick the sale / "Solde" filter (any product list works), click Grab deals. A file svp-DATE.json downloads.
  4. Hoka (test): open hoka.com/en/ca, go to the sale running shoes, scroll to the bottom so every shoe loads, click Grab deals. It only saves what's on your screen. File saved.
  5. On GitHub, open the saved-pages folder → Add file → Upload files → drag in both files → Commit.

It reads up to 80 MEC pages, 150 REI pages and 150 Backcountry pages, about 2 seconds apart, just like clicking "next". Files older than 10 days are ignored automatically, so you never need to delete old ones.
