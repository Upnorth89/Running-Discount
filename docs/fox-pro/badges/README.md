## The number on the founding badge = LIVE TEXT (never baked in)
Overlay on founding-badge-base.png, centred: `top: 80.2%` of the badge, Source Serif 4 weight 800 (email: Georgia bold),
`font-size: 9.2%` of the badge width, colour `#E3B85A`, letter-spacing .03em, 3 digits ("001"). Preview: scratchpad render badge-num4.
At 64 px it is tiny but readable; below 64 px use founding-icon.png (no number) + the number in text beside it ("Founding Fox #007").

## Number rules (members-lead, Nov 7)
- Numbers in real payment order (pro_join). Test numbers never use real ones.
- Refunded within the 30 days = the spot never counted: the number goes back and the next payer gets the lowest free number.
- Cancelled later = number retired forever; if they return they pay $45 and get the Pro badge.
- Later (not launch): a small mark on the ring per renewed year ("since 2026").
